놀화상기 사용 설명서

빠른 시작

  1. 자료 보여 주기 · PC에서는 상단 카메라 목록에서 내장 카메라·웹캠·USB 실물화상기를 선택할 수 있습니다. 휴대폰에서는 가운데 카메라 시작을 누릅니다. 브라우저가 권한을 물으면 허용을 누릅니다.
  2. 원하는 영상 고르기 · PC에서는 상단 목록, 휴대폰에서는 설정 → 카메라에서 장치를 고릅니다. 영상 방향을 바꾸려면 설정의 좌우 반전 또는 상하 반전을 누릅니다.
  3. 모니터에 크게 띄우기 · 전체화면을 누르고, 필요하면 도구 접기로 도구 모음을 줄입니다. 다시 보려면 도구 펴기를 누릅니다.
  4. 카메라 없이 시작하기 · 칠판 또는 화이트보드를 누르면 바로 필기할 수 있습니다.

카메라 · 캡처 · 저장

일시정지 · 재생
일시정지하면 지금 장면이 화면에 남습니다. 재생하면 실시간 영상으로 돌아오고 화면 위 필기가 이어집니다.
캡처 · 저장
캡처하면 한 장으로 고정되고 펜을 바로 쓸 수 있습니다. 캡처에 새로 표시한 내용은 재생 전에 저장하세요. 저장을 누르면 현재 화면과 필기를 PNG로 내려받습니다.
좌우 · 상하 반전
거울처럼 좌우를 뒤집거나 위아래를 뒤집습니다. 두 방향은 각각 켜고 끌 수 있습니다.
확대 · 축소
화면 아래의 ＋와 −로 100~600% 사이에서 조절합니다. 영상 위에서 마우스 휠을 돌리면 포인터가 가리키는 부분을 중심으로 확대됩니다. 설정 → 확대 배율에서 세밀하게 조절할 수 있습니다.
이동 · 영점
이동 모드에서 확대된 영상을 드래그해 원하는 부분을 보여 줍니다. 영점은 100%와 화면 중앙으로 되돌립니다.
화면 채우기 · 회전
설정에서 화면 전체를 채우면 영상 가장자리가 일부 잘릴 수 있습니다. 영상 전체 보기로 돌아올 수 있습니다. 90° 회전은 옆으로 놓인 자료의 방향을 돌립니다.
해상도 · 밝기 · 대비
자동은 2K를 먼저 시도합니다. 실제 해상도는 영상 아래 상태에 표시됩니다. 영상이 끊기면 HD 720p로 낮추고, 자료가 어두우면 밝기와 대비를 조절합니다.

화면이 나오지 않거나 수업 중 끊겼을 때

  1. 권한이 차단됐을 때 · 브라우저 주소창의 사이트 설정에서 카메라를 허용한 뒤 카메라 시작을 누릅니다. Windows라면 설정 → 개인 정보 및 보안 → 카메라에서 카메라와 데스크톱 앱의 접근도 확인합니다.
  2. 카메라가 목록에 없을 때 · 기기의 전원과 USB 영상 모드를 확인하고 허브 대신 PC에 직접 연결합니다. Windows 카메라 앱에서 영상이 잡히는지 확인한 뒤 그 앱과 화상회의 앱을 닫습니다.
  3. 수업 중 USB가 빠졌을 때 · 연결이 복구되면 재생할 수 있습니다. 일시정지나 캡처 중이었다면 기존 화면과 필기를 먼저 저장할 수 있습니다. 자동 연결을 멈추려면 연결 취소를 누릅니다.

칠판 · 화이트보드 · 텍스트

칠판 · 화이트보드
화면을 오가도 두 보드의 작업은 각각 남습니다. 새로고침하거나 창을 닫기 전에 저장으로 PNG를 남깁니다.
펜 · 형광펜
펜으로 쓰고, 형광펜으로 글자가 비치게 표시합니다. 필기 설정에서 펜 색과 굵기를 바꿀 수 있습니다.
텍스트 넣기
텍스트를 누르고 글을 놓을 위치를 클릭한 뒤 내용을 씁니다. 키보드에서는 N으로 입력 창을 바로 열 수 있습니다.
텍스트 고치기
텍스트 도구를 켜고 기존 글자를 클릭하거나, 입력 창의 글상자 선택에서 기존 글을 골라 수정·삭제합니다.
필기·텍스트 지우기
필기 설정에서 현재 보드의 내용을 지울 수 있습니다. 확인 창에서 취소하면 그대로 남습니다.

수업 타이머

  1. 타이머를 누르고 1·3·5·10분을 고르거나 1~180분을 직접 입력한 뒤 시작합니다.
  2. 접기를 눌러도 시간이 계속 줄어듭니다. 도구 모음에서 남은 시간이나 종료를 확인합니다. 소리는 나지 않습니다.
  3. 일시정지와 계속으로 이어서 재고, 초기화로 정해 둔 시간으로 돌아갑니다.

Windows 앱 다운로드

  1. Windows x64 앱 받기를 누릅니다. PC에서는 하단의 앱 받기로도 받을 수 있습니다.
  2. 브라우저의 다운로드 목록이나 다운로드 폴더에서 놀캠.exe를 찾아 실행합니다. 설치 과정 없이 열립니다.
  3. 카메라를 꽂고 놀캠을 열면 자동 연결을 시도합니다. 여러 장치가 있으면 설정 → 카메라에서 고릅니다. 파일을 받은 뒤에는 인터넷 없이도 쓸 수 있습니다.

Windows x64용 무서명 파일입니다. 학교 PC 정책이나 Windows 보안 경고로 실행이 제한되면 웹에서 놀캠을 계속 사용할 수 있습니다.
